# Zira Fonts

Custom fonts built from [Iosevka](https://github.com/be5invis/Iosevka): **Zira Mono**, **Zira Sans**, **Zira Serif**.

[中文版](README.zh-CN.md)

## Web Usage (jsDelivr)

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/zira-font@latest/zira/fonts.css">
```

Or import in CSS:

```css
@import url('https://cdn.jsdelivr.net/npm/zira-font@latest/zira/fonts.css');
```

Then:

```css
font-family: 'Zira Mono'; /* or Zira Sans / Zira Serif */
```

Pin a version for production:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/zira-font@0.1.0/zira/fonts.css">
```

## Desktop Fonts

Download `zira-ttf.zip` / `zira-woff2.zip` from [Releases](https://github.com/dangpang/zira-font/releases).
